# Object-Oriented Programming in Python 🐍

This project demonstrates the core concepts of **Object-Oriented Programming (OOP)** using the Python programming language. It is designed to help understand how OOP principles are applied in real-world Python applications.

---

## 📌 Features

- Clear examples of OOP concepts
- Beginner-friendly Python code
- Well-structured and easy to extend
- Suitable for academic and practice projects

---

## 🧠 OOP Concepts Covered

- **Class & Object**
- **Encapsulation**
- **Inheritance**
- **Polymorphism**
- **Abstraction**
- **Constructors (`__init__`)**
- **Method Overriding**
